빙하 융해 모니터

전 세계 빙하가 연대별로 얼마나 더워지고 녹고 있는지, 그리고 페루 빙하호의 실시간 붕괴 위험을 함께 봅니다

데모 데이터입니다. 실시간 API(Open-Meteo · USGS)에 연결하지 못해 형태만 같은 합성 시계열을 보여주고 있습니다. 화면의 모든 수치는 실제 관측값이 아니며 판단 근거로 쓸 수 없습니다.

모니터링 지점

위성 화면에서 하얗게 보이는 것이 빙하, 청록색으로 고인 것이 빙하호입니다. 점을 누르면 상세 분석이 열립니다. ● 빙하호 · ◆ 빙하 관측 지점

지점별 현황

행을 누르면 지도가 그곳으로 이동하고 아래에 상세 분석이 열립니다. 작은 그래프는 최근 7일 기온이며, 가로 점선이 0 °C입니다 — 선 위로 올라간 만큼 녹은 것입니다.

페루 빙하 배경 지표

아래는 실시간 값이 아니라 공표된 국가 인벤토리·연구 결과의 참고 수치입니다.

산정 방식과 한계

점수 읽는 법

  • 관심 (0~24) — 평시 범위입니다.
  • 주의 (25~49) — 융해·강수가 평시보다 높습니다. 추이를 지켜볼 구간.
  • 경계 (50~74) — 여러 요인이 동시에 올라가 있습니다. 현장·하류 확인이 필요한 수준.
  • 심각 (75~100) — 조건이 크게 악화됐습니다. 공식 기관 발표를 반드시 함께 확인하세요.

점수는 지금 조건이 얼마나 나쁜가를 나타내지, 붕괴 확률이나 남은 시간을 뜻하지 않습니다.

어떻게 계산하나

  • 빙하 융해 (30%) — 빙하 말단 고도로 내려 맞춘 기온의 지난 7일 양의 도일(PDD). 융해수 유입량의 대리 지표.
  • 0 °C 동결고도 (20%) — 최근 3일 평균 동결고도가 빙하 말단보다 높을수록 융해면이 넓게 노출됩니다.
  • 강우 유입 (25%) — 최근 3일 + 향후 3일 강우. 호수 수위를 올리고 모레인 댐을 약화시킵니다.
  • 급격한 온난화 (10%) — 향후 3일 평균기온에서 지난 7일 평균을 뺀 값.
  • 지진 활동 (15%) — 반경 250 km · 30일 내 지진을 규모/거리/경과일로 감쇠. 빙벽 붕락과 댐 붕괴의 방아쇠.

다섯 요인을 0~1로 정규화해 가중 합산한 뒤, 지점별 정적 취약도(댐 형식 · 용적 · 하류 노출 · 저감 시설)를 0.5~1.0 배율로 곱해 0~100으로 환산합니다.

데이터 출처

  • Open-Meteo Forecast API — 기온 · 동결고도 · 강수 (과거 14일 + 예보 7일, 지점 고도로 다운스케일)
  • Open-Meteo Archive API — ERA5 재분석 기반 장기 기온 추세
  • USGS Earthquake Catalog — 페루 권역 M4.0+ 지진
  • 정적 제원 — INAIGEM/ANA 국가 빙하·빙하호 인벤토리 및 GLOF 연구 문헌 기반 근삿값

한계

  • 호수 수위 · 모레인 댐 변위 · 빙하 두께를 직접 관측하지 않습니다. 기상·지진이라는 외부 조건만 봅니다.
  • GLOF의 상당수는 기상과 무관한 빙벽·암반 붕락으로 촉발되며, 이 모델은 그 순간을 예측하지 못합니다.
  • 가중치는 문헌의 정성적 인과관계를 반영한 값이지 관측 사례로 보정(calibration)한 값이 아닙니다.

⚠ 이 대시보드는 공개 데이터로 만든 스크리닝 지표입니다. INAIGEM · SENAMHI · INDECI 등 페루 당국의 공식 조기경보를 대체하지 않으며, 대피·통제 등 실제 방재 판단의 근거로 사용해서는 안 됩니다.
